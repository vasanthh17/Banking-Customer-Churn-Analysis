# Banking Customer Churn Analysis

## Business objective
Identify customer segments with elevated churn risk and translate the findings into retention actions.

## Workflow
1. Generate/inspect dirty banking customer data.
2. Clean duplicates, missing values, inconsistent categories, invalid numeric values and outliers.
3. Analyze KPIs and churn drivers in Python/Pandas.
4. Reproduce business questions in MySQL.
5. Build an interactive Power BI dashboard.
6. Publish project documentation and portfolio assets to GitHub.

## Dataset
- 10,000 unique customers in the clean dataset.
- Dirty source contains duplicates and intentionally introduced quality issues.
- Fields cover demographics, financial profile, engagement, satisfaction and churn.

## Portfolio story
The analysis focuses on **who is leaving, why they may be leaving, and where retention efforts should be concentrated**.

## Important note
This is a portfolio/synthetic dataset designed for practicing data analysis. It is not real bank customer data.
